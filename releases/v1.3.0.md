# v1.3.0 — Double-click to install

**A printer file now opens like a document.** Double-click a `.ssb`, drop it on
the SpoolSmith window or on `spoolsmith-gui.exe`, or copy it in Explorer and
press **Ctrl+V** in the app. It opens straight onto one review sheet: the
printer, where the file came from, anything to know first, and the exact steps
SpoolSmith will take. Nothing changes until you confirm, once.

## Desktop

- **The apply sheet** replaces the Review and apply page. It opens for every
  change — a printer file, a printer found on the network, a saved setup, or
  Remove and Change address on This PC — and prepares its preview as soon as it
  opens. **Details** shows the full plan; **More options** holds offline setup,
  updating an existing queue and, for removals, removing the driver.
- **No more "close the app and run as administrator".** If SpoolSmith isn't
  elevated, the Install button carries the Windows shield. Press it and Windows
  asks for permission; SpoolSmith reopens on the same printer, prepares the plan
  again and asks you to confirm it there. Say no and nothing changes.
- **Copy notes for the ticket.** When a change finishes, the sheet shows each
  step's result, and one button copies a plain-text summary to the clipboard.
- **This PC is a table.** Select one or several printers and choose **Copy 1
  printer...** or **Copy N printers...** (several make one `.zip` set), or press
  **Ctrl+C** and paste the `.ssb` files into a folder, a share or a chat.
  Ctrl+A selects every printer that can be copied. Printers SpoolSmith can't
  copy are greyed, with the reason.
- **Open `.ssb` files with SpoolSmith.** On first run the app offers to open
  printer files when you double-click them, for your Windows account only. Turn
  it on or off under **More**. A second double-click while SpoolSmith is open
  goes to the window that's already open.
- **Two places, not seven.** The sidebar is **This PC** and **Add a printer**.
  Intune packaging, Inspect, the action log and saved setups are under **More**.
- **Add a printer** lists the printers on the network the PC is connected to,
  scanned at startup. A different network or a single address is one click away.
- The window opens at its intended size (earlier versions could open several
  screens tall), with the sidebar flush to the edge.

## The driver catalog is being retired

SpoolSmith copies a printer that already works; it doesn't need to look your
printer up in a model list. The desktop no longer offers the driver catalog,
"Use catalog identification instead...", or the printer-family override.

On the command line, `catalog probe`, `catalog families` and catalog-driven
`install <ip>` (with `--force-family`) still work in this release but print a
notice that they are **pending deprecation** and will be removed in a future
build. The notice goes to stderr; stdout and `--json` output are unchanged.
`install --profile` is not affected. Use `copy` and `apply` instead.

## Notes

- Nothing about the plan, its fingerprint (`--plan-hash`) or the confirmation
  changed. The CLI still refuses to change Windows unless it's already running
  as administrator; only the desktop offers to elevate, and only when you press
  the shield button.
- The `.ssb` format is unchanged (version 1). Printer files and sets from v1.1
  and v1.2 open as before.
- The `.ssb` association is stored under your user account
  (`HKCU\Software\Classes`), never machine-wide, and never for `.zip`.
- Ctrl+C writes printer files to a SpoolSmith folder under your temp directory
  so they stay available to paste; copies older than a day are cleaned up.
