# v1.4.0 — USB copies, WSD conversion, and Windows automatic IPP setup

SpoolSmith now copies hostname-backed RAW ports, USB printer drivers, and supported
WSD queues into portable printer files.

- Hostname ports resolve to a literal IP during copy and carry a warning about
  DNS or DHCP changes.
- USB copies use `.usb.ssb`. A bundled driver can be staged and registered before
  the printer is connected. Apply again after Windows detects its USB queue;
  select a differently named queue in the desktop or with `--usb-queue`.
- WSD copy verifies the device identity and current IP. RAW TCP/IP is preferred:
  the source driver is kept when appropriate, or an existing unambiguous RAW
  mapping at the same IP supplies the OEM driver. Microsoft IPP Class Driver uses
  a verified IPP endpoint as fallback when no usable RAW driver mapping is known.
- Both desktop and CLI use the same conversion, copy, and import path. Copied
  files describe the selected address and driver before installation.
- Windows automatic setup discovers IPP by IP and uses Microsoft's inbox class
  driver. The desktop driver picker and CLI `add <ip> --windows-driver --name
  <queue>` share this workflow. `profile capture` also accepts `--windows-driver`.
  This does not promise automatic acquisition of arbitrary OEM drivers.

WSD conversion needs a reachable printer. IPP endpoint discovery currently checks
common paths on TCP 631; IPPS-only endpoints and LPR mapping remain unsupported.
Creating a new IPP queue requires live directed discovery. RAW transport
availability does not prove driver compatibility; check a test page after setup.
