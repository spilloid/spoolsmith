# v0.6.0 — Copy, manage and carry printer setups from the desktop

The desktop now exposes the workflows previously available through the CLI:

- **This PC** lists Windows printers and offers copy to a `.ssb` file, address changes and removal. Driver files can travel with a copied printer.
- **Add a printer** combines discovery, direct-IP setup, saved profiles and opening copied printer files. Review supports offline provisioning and updating an existing queue.
- Saved setups offer editing with backups, local configuration checks and bulk JSON export/import. The CLI provides `profile export-all` and `profile import-all` too.
- **Tools → Inspect** verifies printer bundles and shows their manifests. A lighter layout, Segoe UI typography and blue accents refresh the native desktop.

Bulk JSON transfer preserves every supported profile property, evidence and package reference. It validates the entire collection and refuses filename collisions. It does not embed driver archives or install printers; carry referenced archives separately and review Windows changes individually.

Add, configure, remove, apply and address changes require a preview and explicit confirmation. Address changes now reject a queue whose driver or original port changed after preview. CLI and GUI copy/apply share the same bundle implementation.

Release packaging now builds both executables, stamps the CLI version, embeds the GUI manifest, suppresses the GUI console and uses portable ZIP paths. The workflow builds the actual release tag.

Intune remains unavailable in the shipped command table and disabled in the GUI pending tenant validation. Existing limitations remain: no automatic driver downloads, no verified live address-change mutation or physical print through a bundle-staged driver, and Windows can retain an unused driver after asynchronous queue removal. The prior v0.5.0 hardware results do not constitute a new hardware pilot for this GUI release.

Validation: Linux and Windows CI passed, along with all 27 hosted desktop checks. The GUI run covers navigation, saved-setup handoffs, direct-IP setup, minimum-size layouts, modal close and refusal to apply an offline profile with a missing driver. See [the validation record](https://github.com/spilloid/spoolsmith/blob/main/docs/validation/2026-09-16-gui-release.md).
