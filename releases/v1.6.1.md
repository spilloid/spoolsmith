# v1.6.1: verify installed drivers and set up a whole printer set

A stable release with stronger driver checks and the desktop printer-set review prepared
for v1.6.0. Both the portable ZIP and MSI contain the CLI and desktop app.

## Driver checks

- A matching driver name alone no longer counts as installed. SpoolSmith checks the
  native Windows driver environment and the presence of the driver binary, data file,
  configuration DLL and declared dependencies. V4 drivers may omit a configuration DLL.
- An incomplete or wrong-architecture registration no longer suppresses installation
  from a carried driver or supported local vendor archive. After installation, the same
  checks must pass before queue setup continues. Healthy registrations are still reused.
- Local status and Intune detection use the same checks. Missing-driver guidance now
  explains that an existing driver may need repair.
- Driver staging remains under Windows' temporary directory, including when SpoolSmith
  and the printer set are on removable media. Publisher trust and confirmation are unchanged.

The change addresses a confirmed gap in verification. The reported Windows driver wizard
when opening printer properties has not been reproduced on the affected PC. File presence
does not prove the driver's UI can load or that physical printing works.

## Desktop printer sets

- Drop or open a set ZIP to review all its printers together. Each printer is checked
  first, with its plan and a tick box; unavailable or unchanged printers stay unticked.
- Confirm the selected list once with **Set up N printers**. Each printer runs only its
  reviewed plan. One damaged printer file does not prevent reviewing the others.
- See each result in the list and use **Copy summary for the ticket**. Set-wide offline
  and update options are available; **Review only this printer...** opens a single sheet.
- The administrator hand-over preserves the selection and previews again before asking
  for confirmation. The CLI retains its per-printer confirmation or explicit `--yes`.
- Inspecting a set no longer leaves extracted printer files in `%TEMP%`.
- The set review fits the monitor's work area, with scrolling content and persistent
  action buttons. Long driver-error messages no longer stretch its heading off screen.

## Upgrading

Driver commands and their reviewed-plan fingerprints change. Re-approve scripted
`--plan-hash` values using this version before rolling it out. Printer file formats are
unchanged. A settings-only file still requires a compatible, complete driver on the PC.

## Validation and limits

Regression tests run the generated commands in real Windows PowerShell with driver and
installation doubles plus actual temporary files. They cover missing configuration/data
files and dependencies, wrong and duplicate architectures, V3/V4 differences, retrying a
carried driver, rejecting an incomplete installation, healthy re-apply and publisher trust.
The release also runs repository CI, desktop automation and signed MSI lifecycle checks.
Windows and Linux CI passed, including MSI install, upgrade and uninstall. The full desktop
suite passed **42 of 42**; the refreshed set-review screenshot comes from that run. Site
checks passed at 360, 390, 768 and 1440 pixels with no accessibility violations.
A read-only Windows test checks a real installed inbox driver when available, alongside
the doubles, to verify the actual PrintManagement property names and file paths.

A clean two-PC apply with physical output, the reported properties-wizard repair, a real
Windows Update driver download, and publisher-trust cleanup on uninstall remain unverified.
