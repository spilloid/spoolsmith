# v1.4.0 release verification

Release commit: `4e777c133168778cc6035be738ec6d1d52c31527`, merged through
[PR #25](https://github.com/spilloid/spoolsmith/pull/25).

Windows and Linux build/vet/tests and MSI build/lifecycle CI passed. The local
complete GUI suite passed 34/34 against final v1.4.0 binaries after named-control
lookups gained the existing button helper's bounded rendering wait.

[Release workflow](https://github.com/spilloid/spoolsmith/actions/runs/36959250631)
built and signed the ZIP payload, verified it, built and signed the MSI, and
passed signed MSI payload and install/uninstall checks. The first attempt lacked
a Git tag because creating a draft does not create it; the tag was then created
at the release commit. The rerun's final upload job could not resolve the draft
release by tag. The verified workflow artifacts were downloaded and attached to
the draft through the authenticated release CLI; no unsigned fallback was used.

The attached ZIP, MSI, and both checksum files were downloaded again. Both
SHA-256 checksums matched. Both EXEs and the MSI had valid Joseph Spillers
Authenticode signatures and Microsoft timestamp countersignatures. Go metadata
identified module v1.4.0 and the exact release commit, with vcs.modified=false.
The downloaded CLI enumerated the original four printers successfully and the
downloaded GUI opened a window titled SpoolSmith, then closed. These checks made
no printer changes. The CLI has no version command; metadata was used instead.

Hardware evidence and limits are in
[the WSD validation record](2026-10-01-wsd-conversion.md). Clean-target USB
staging, cross-PC apply, and physical printing remain unverified. This release
does not claim automatic OEM acquisition or in-place WSD driver migration.
