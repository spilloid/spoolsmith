# v1.5.0 release verification

Pre-merge record. The release workflow, signing and downloaded-artifact checks are
appended after the release is published.

**Passed locally (Windows 11, 125% display scaling):** `go build ./...`, `go vet ./...`
for Windows and Linux, and the full `go test ./...`. The complete desktop FlaUI suite
passed 40/40: the 34 existing cases plus 6 new accessibility cases
(`AccessibilityTests`, output in `dist/gui-accessibility.txt`). One earlier run failed
a More-menu lookup that passed on rerun. The site check (`test/site/check.cjs`) found
no horizontal overflow at 360/390/768/1440 px and no axe WCAG 2 A/AA or 2.1 AA
violations.

**Found and fixed during verification:** Tab and Shift+Tab did not move focus in the
main window on 5 of 6 pages (confirmed with Win32 focus queries); fixed by routing
those keys through `IsDialogMessage`. A read-only adversarial review (Codex
`gpt-6.1-sol`, xhigh) found seven confirmed defects and one plausible; all fixed.
Details: [dev-process](../dev-process.md), 2026-10-02.

**Not verified, and why this is stated here:**

- A real Windows Update driver download. Elevated validation ran on 2026-10-02
  (`dist/validation/printers-20261002-221633.txt`): with the Brother HL-L2315D PC's WSD
  queue temporarily removed, the IPP apply switched the queue from the Microsoft IPP Class
  Driver to `Brother HL-L2315D series` (`applied`), a re-apply reported `in-use`, and the
  original WSD queue was restored with a verified WSD port. That Brother driver was already
  in the DriverStore (installed 2026-09-15), so this proves the registered-driver path and the
  live switch, not a Windows Update download. A read-only scan on that PC found no pending
  driver updates, so the download path has not run on hardware. (An earlier run the same day
  logged `wanted=false` because the test dropped the discovered IPP model; fixed in `9adbcbe`.)
- Display scales other than 125%, Windows high contrast, a screen reader, and color
  contrast of native controls. Accessible names are internal ids, and the two results
  tables expose an empty name through UI Automation.
- Clean-target USB staging, cross-PC apply and physical printing (unchanged from v1.4.0).
- The board's decision on the native-driver step (ratify, amend or reverse) is pending:
  `corporate-strategy/board/meetings/2026-10-02-spoolsmith-v1-5-native-driver/`.
