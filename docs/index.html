Repeatable add, configure, and remove

Built for everyday IT

Run it again.
It’s still one printer.

Repeated setup should be uneventful. SpoolSmith reuses a matching queue and port, and asks you to use configure when the queue’s settings differ.

Need it gone? Remove the queue from its profile. Shared ports and drivers stay available to the printers that still use them.

Example · reapplying a saved profile
> .\spoolsmith.exe add --profile profiles\office.json

A small Windows tool.
Your own printer library.

Build the current source with Go 1.22 or later — the desktop app and the command-line tool come from the same repository — or check the release notes for the features in a packaged build.

Build from source ↗Browse releases ↗
Before you add a printer

Run as administrator and have a reachable network printer. Install its compatible Windows driver first, unless you’ve configured a supported local package.

02 / CHOOSE YOUR STARTING POINT

Build it, then just open it.

Keep the manifest beside the executable — it is what asks Windows for the access printer changes need. Run it as administrator when you are ready to apply a change; finding printers and saving their settings works without that.

go build -ldflags="-H windowsgui" -o dist/spoolsmith-gui.exe ./cmd/spoolsmith-gui
Copy-Item cmd/spoolsmith-gui/spoolsmith-gui.exe.manifest dist/

.\dist\spoolsmith-gui.exe

The app scans the network this PC is on as it opens. Pick a printer, confirm its driver, and review the plan before anything is applied.

Capture it once. Keep it handy.

Replace the example IP and driver name with yours. To find the driver’s exact name, run Get-PrinterDriver | Select-Object Name.

.\spoolsmith.exe profile capture 192.168.1.50 profiles\office.json --name "Office Printer" --driver "EXACT WINDOWS DRIVER NAME"

.\spoolsmith.exe add --profile profiles\office.json --dry-run
.\spoolsmith.exe add --profile profiles\office.json

The preview shows the setup. The next command asks you to confirm it.

Find the address first.

Replace the example subnet with the network you’re working on. Discovery scans up to 256 addresses and lists printer candidates.

.\spoolsmith.exe discover 192.168.1.0/24

Choose a candidate’s IP, then use “I know the IP” to save its profile. Discovery doesn’t choose a compatible driver for you.

Bring the profile. Review the setup.

Copy the saved profile to this PC and make sure its driver is installed. SpoolSmith checks the printer’s current model details against the capture.

.\spoolsmith.exe add --profile profiles\office.json --dry-run
.\spoolsmith.exe add --profile profiles\office.json

Matching queue and port settings are reused. Your profile remains available for the next workstation.

Available in source

The desktop app

Scans the network this PC is on as it opens, with a subnet override and direct IP entry. A saved printer goes straight to its reviewed plan; a new one gets a driver suggested from the model it reports. The command-line tool does the same work and is what the packaged v0.2.0 release contains.

Available in source

Discovery and reusable profiles

Known-IP capture, subnet discovery, and add/configure/remove. Profiles can use an explicitly chosen compatible driver beyond the built-in HP and Brother identification catalog.

Verified on hardware

Brother HL-L2315D

Discovery and queue setup worked. A second add left the queue and port unchanged. The operator sent a test print and watched it work. The screenshots above are the real app, scanning a real network.

In progress

Less driver preparation

A local package recipe supports the verified Brother driver on Windows x64. Other drivers still need local installation. Automatic downloads and broader package coverage are next.
